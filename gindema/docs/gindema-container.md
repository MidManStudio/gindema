# gindema-container

## Overview
Encrypted asset container. Wraps dixscript's own DLM pipeline (compress, encrypt, audit) with gindema-specific defaults: metadata stripped by default, honeypot/decoy blocks, per-chunk lazy decrypt timed to in-game use.
