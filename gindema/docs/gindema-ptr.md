# gindema-ptr

## Overview
Type-erased pointer primitives, vendored from mid-engine's mid-ptr crate (itself ported from bevy_ptr), for weaving integrity checks into memory access without an obvious branch. mid-ptr is not published on crates.io, which is why this is vendored rather than a normal dependency. Scaffolded as an empty stub for now; the real source to pull in lives at mid-engine/crates/mid-ptr/src/lib.rs.
